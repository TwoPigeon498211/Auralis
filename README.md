# Auralis

Auralis is a purpose-built music oriented operating system currently in development.

## Vision

Create a designated music appliance, which boots seamlessly into a beautiful audio-visual experience requiring no linux knowledge or experience from the user. 

## Status

Core audio functionality is in development

✅Seperate audio and video into seperate outputs
✅Airplay
✅Spotify Connect
⏳Bluetooth Connection
